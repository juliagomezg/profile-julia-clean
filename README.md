# Julia Gómez - Portfolio Creativo

Una landing page elegante y moderna para mostrar proyectos creativos que combinan escritura, desarrollo e investigación en IA.

## 🎨 Características

- **Diseño Responsivo**: Se adapta perfectamente a dispositivos móviles y desktop
- **Imágenes Reales**: Incorpora tus fotografías y diseños creativos
- **Animaciones Suaves**: Efectos de hover y scroll animations para una experiencia interactiva
- **Performance Optimizada**: Carga rápida con animaciones CSS nativas
- **Tipografía Elegante**: Combina 'Crimson Text' para títulos y 'Inter' para texto

## 📁 Estructura del Proyecto

```
profile-julia/
├── index.html          # Página principal
├── img/                # Carpeta de imágenes
│   ├── cerebro.png     # IA/Research (foto perfil + proyecto AI)
│   ├── escritorio.png  # Desarrollo/Workspace (proyecto escritura)
│   ├── lineas.png      # Elementos gráficos (background hero + proyecto visual)
│   ├── piezas.png      # Componentes/Design (background about + proyecto ethics)
│   ├── colores-calidos.png    # Proyecto social impact
│   ├── colores-fuertes.png    # Proyecto web development
│   └── sobre-colores.png      # Background sección contacto
└── README.md           # Este archivo
```

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Estilos modernos con variables CSS, Flexbox y Grid
- **JavaScript**: Animaciones de scroll e interacciones
- **Google Fonts**: Tipografía Crimson Text + Inter
- **Intersection Observer API**: Animaciones on-scroll optimizadas

## 🎯 Secciones

### 1. Hero

## 📱 Responsive Design

- **Desktop**: Grid de 2 columnas, navegación completa
- **Tablet**: Grid adaptativo, espaciado optimizado  
- **Mobile**: Columna única, navegación minimalista

## ⚡ Performance

- Imágenes optimizadas en PNG
- CSS puro sin dependencias externas
- Animaciones con GPU acceleration
- Lazy loading con Intersection Observer

## 🛠 Cómo Usar

1. Abre `index.html` en tu navegador
2. Personaliza el contenido en el HTML
3. Reemplaza imágenes en la carpeta `img/`
4. Ajusta colores en las variables CSS
5. Modifica links de contacto y proyectos
